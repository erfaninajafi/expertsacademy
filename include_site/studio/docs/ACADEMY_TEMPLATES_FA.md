# قالب‌های فارسی آکادمی کارشناسان در Page Studio

این پوشه شامل ۱۵ قالب آماده فارسی بر پایه کامپوننت‌های ComponentRegistry است.
**صرفاً افزودن این فایل‌ها به Git قالب‌ها را در دیتابیس نصب نمی‌کند**؛ نصب هر محیط باید با دستور جداگانه انجام شود.

## فایل‌ها

- `include_site/studio/data/academy_templates_fa.json`: منبع اصلی ۱۵ تعریف قالب و متن اولیه
- `include_site/studio/bin/install_academy_templates.php`: نصاب CLI که از فایل JSON استفاده می‌کند
- `include_site/studio/docs/ACADEMY_TEMPLATES_FA.md`: این راهنما

## نصب در یک محیط تازه یا سرور

بعد از انتقال کد و اجرای migration های Page Studio، در ریشه پروژه:

```bash
php include_site/studio/bin/install_academy_templates.php --dry-run
```

Dry-run با قرارداد فعلی کامپوننت‌ها اعتبارسنجی می‌کند و **در دیتابیس چیزی نمی‌نویسد**.
پس از گرفتن بکاپ **دیتابیس درست همان محیط** و بررسی نتیجه:

```bash
php include_site/studio/bin/install_academy_templates.php --install
```

در لینوکس با XAMPP محلی می‌توان به‌جای `php` از `/opt/lampp/bin/php` استفاده کرد.

## رفتار نصب و ایمنی

- فقط جدول `tbl_studio_templates` هدف است؛ هیچ صفحه‌ای ساخته یا منتشر نمی‌شود.
- ۱۵ شناسه ثابت هستند؛ اجرای مجدد، رکوردهای از قبل موجود را نادیده می‌گیرد.
- اگر شناسه موجود به نام دیگری متعلق باشد، خطا می‌دهد و کل تراکنش به حالت قبلی بازمی‌گردد.
- قالب‌های موجود با همان شناسه **به‌روزرسانی نمی‌شوند**. تغییر نسخه محتوایی در آینده به فرآیند نسخه‌بندی مستقل نیاز دارد.
- زمان `--install` توکن‌های پوسته پیش‌فرض فارسی فعلی برای سند قالب خوانده می‌شود؛ در `--dry-run` اتصال دیتابیس نیاز نیست.
- تصاویر یا لوگوهای غیرواقعی در قالب‌ها ذخیره نمی‌شود؛ تصاویر را پس از ساخت صفحه انتخاب کنید.
- لینک‌های اولیه و فرم‌ها را قبل از انتشار صفحات واقعی آزمایش کنید.

## بررسی سریع

```bash
php -l include_site/studio/bin/install_academy_templates.php
python3 -m json.tool include_site/studio/data/academy_templates_fa.json >/dev/null
```

منشأ طراحی: ساختار و خدمات وب‌سایت `expertsacademy.ir`، با اقتباس از صفحات در دسترس.
این داده‌ها کپی کامل صفحات فعلی سایت نیستند و باید پیش از انتشار نهایی بازبینی محتوایی شوند.
