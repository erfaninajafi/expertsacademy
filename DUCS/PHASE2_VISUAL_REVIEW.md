## Baseline review history

The first complete run captured 1,464 images and passed 488 automated accessibility audits. Whole-page RTL checks then found duplicated named section landmarks from repeated default headings; redundant outer region labels were removed without a visual change. Review also corrected an RTL font selector and bundled CMS fonts using portable relative paths. The affected 488 Persian images were intentionally refreshed with font/accessibility checks. A subsequent comparison exposed locale-order-dependent fallback fonts for decorative arrows; these were replaced by reviewed inline SVG and a pixel-equality regression test was added. All 1,464 final SVG compositions are recaptured and compared in four disjoint read-only shards, with exact merged coverage and source fingerprints. The final complete comparison does not update snapshots. Interrupted or diagnostic attempts are not counted as passing evidence.

The root-installation test validates the actual alternative URL layout and font loading. The final complete matrix report is `phase2-visual/component-matrix.json`; original capture and reviewed RTL-refresh reports are retained separately. `screenshot-manifest.json` records SHA-256 for all 1,464 final PNGs, and `gallery-manifest.json` records all 240 generated WebPs.

## Limits

Automated pixel comparisons use installed Chrome and a fixed font/theme fixture, reduced motion, decoded media and a 0.05% pixel threshold. They protect these captured compositions, not every future content combination or every browser. Desktop contact-sheet inspection is complemented by complete mobile/RTL/dark page screenshots and automated scenario checks. Illustrative sample copy is not approved public editorial content.
